# مكتبة الطلبات الذكية — PromptsArabic

موقع عربي ثابت RTL يضم 40 برومبتا أصليا في 10 أقسام. أربع مهام في كل قسم مع حقول ومثال إدخال وجزء من مخرج متوقع وتوجيهات مراجعة.

## التشغيل

افتح `index.html` مباشرة أو شغل من هذا المجلد:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا تحتاج إلى Node أو عملية بناء لتشغيل الموقع. يعمل البحث والتخصيص دون خادم. النسخ يستخدم Clipboard مع بديل تحديد النص وexecCommand إذا تعذر ذلك.

## الصفحات

الرئيسية، الأقسام والاستكشاف، مخصص البرومبت، أمثلة الطلبات، المفضلة، الاستخدام والخصوصية. التنقل بمسارات hash مناسب لـ GitHub Pages ولمسار مشروع فرعي.

## بنية الملفات

- `index.html`: هيكل الصفحة والرأس والتذييل.
- `css/style.css`: التصميم المتجاوب (360 بكسل فأكثر).
- `css/font.css`: نسخة فرعية من Cairo مضمنة في CSS لتعمل محليا، تحت OFL، انظر `assets/OFL-Cairo.txt`.
- `assets/`: رسومات SVG أصلية قابلة للتحجيم. لا تستخدم صور الواجهات المرجعية كصفحات.
- `data/catalog.json`: مصدر محتوى القوالب.
- `data/catalog.js`: نسخة المتصفح من نفس المصدر حتى يعمل فتح HTML مباشرة دون fetch.
- `js/core.js`: تطبيع البحث والمرادفات والتصفية واستبدال الحقول.
- `js/app.js`: عرض الصفحات والتخصيص والمفضلة والنسخ.
- `tests/content.test.cjs`: فحص اكتمال القوالب والمتغيرات والمرادفات والمسارات.

بعد تعديل JSON، حدث ملف المتصفح:

```sh
python3 -c "import json,pathlib; p=pathlib.Path('data'); d=json.loads((p/'catalog.json').read_text()); (p/'catalog.js').write_text('window.PROMPTS_CATALOG = '+json.dumps(d,ensure_ascii=False)+';\\n')"
node tests/content.test.cjs
```

## النشر على GitHub Pages

استخدم المستودع `kgcfod-ops/-promptsarabic-smart-library-`. ارفع الملفات بحيث يوجد `index.html` في الجذر. ثم Settings → Pages → Deploy from a branch → main → /(root) → Save. انتظر نجاح النشر واقرأ الرابط الذي يعرضه GitHub. لا يحتاج المشروع إلى GitHub Actions أو أسرار.

## حدود التشغيل والخصوصية

المفضلة تحفظ معرفات القوالب فقط في localStorage في نفس المتصفح. بيانات النماذج لا ترسل لخادم ولا تحفظ بعد إغلاق الصفحة. «طلبات المجتمع» أمثلة احتياجات وليست منتدى أو طلبات منشورة من أشخاص. نموذج الفكرة ينسخ النص فقط ولا يرسله. لا توجد API أو حسابات أو تحليلات استخدام. لا تدخل بيانات الطلاب الشخصية. راجع المخرجات العلمية والتعليمية. المكتبة تنتج نص الطلب ولا تشغل أداة ذكاء اصطناعي أو تنشئ ملفات صوت أو فيديو بنفسها.

الأمثلة توضيحية وقد تعرض جزءا من الناتج المتوقع، ولا تعني أن القوالب جربت على جميع نماذج الذكاء الاصطناعي. فحوص الموقع مستقلة عن جودة استجابة مزود AI.
